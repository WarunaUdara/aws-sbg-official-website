# Rule: AWS SBG USJ Design System Guidelines

When writing, styling, or creating UI components for AWS SBG USJ, agents MUST enforce:

1. **Color Palette**:
   - Primary Orange: `#FF9900`
   - Dark Canvas: `#0A0E17`
   - Surface / Block Navy: `#161F2E`
   - Crisp 1px borders with `rgba(255, 153, 0, 0.2)` or `rgba(255, 255, 255, 0.08)`.

2. **Typography**:
   - Primary: **Space Grotesk** for display headlines, navigation, and body copy.
   - Secondary / Code: **JetBrains Mono** for all brand signatures ("AWS Student Builder Group at University of Sri Jayewardenepura"), tags, metadata, and eyebrows.

3. **Geometric Motifs**:
   - Use the **modular square grid** (`builder-grid` or `builder-grid-orange`) for backdrops.
   - Incorporate **stepped builder mosaic blocks** (sharp 0px corners, square proportions) for technical flair.
   - Use the 7x7 **Builder Chip Logo** (`BuilderChipLogo`) as the primary brand mark.

4. **Restraint & Polish**:
   - High contrast, never muddy.
   - Restrain border radiuses on structural tiles (`rounded-none` or `rounded-sm`).
   - Give text adequate measure (max 65–75ch for body copy).
